# Arte Marina Descalzi

Sitio web de la artista visual Marina Descalzi (tienda, portfolio, galería, blog). Astro, en español, inglés e italiano.

## Comandos

| Comando | Qué hace |
|---|---|
| `npm install` | Instala las dependencias (solo la primera vez) |
| `npm run dev` | Abre la web en local: http://localhost:4321/ |
| `npm run build` | Genera la versión final en `dist/` |

## Dónde está cada cosa

- `src/content/obras/` — una obra por archivo (estado: disponible, vendida o no a la venta)
- `src/i18n/ui.ts` — todos los textos de la web en ES, EN e IT
- `src/pages/[lang]/` — páginas
- `public/obras/` — imágenes de las obras
- `docs/estructura.md` — decisiones del proyecto
